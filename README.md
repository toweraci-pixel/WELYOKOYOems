# WELYOKOYOems v1.0

よこきょう的个人主页，主题：Aviation · EMS · Photography

## 已包含
- 首页 / 头像 / 个性签名
- 蓝白 EMS 科技风
- 动态星空背景
- EMS Dashboard + 动态 ECG（纯前端演示）
- 日本时间（JST）
- 兴趣爱好卡片
- 用户提供的航空与机场照片相册
- 手机/电脑响应式布局
- 图片点击放大
- Lifeline 播放器位置预留

## 注意
EMS Dashboard 的心电图和生命体征都是视觉演示数据，不是真实医疗监护数据。

## Lifeline
因为歌曲可能受版权保护，本项目没有内置音频文件。
如果你拥有该音频的使用权，可以创建：

assets/music/lifeline.mp3

然后再把播放器接入。
